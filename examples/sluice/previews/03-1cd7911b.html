What it does

A public URL in front of your service

We give you a public URL for webhooks, store every delivery, and forward it to your local or internal service.

The first line below installs Sluice; the second starts it and forwards each delivery to localhost:3000.

Install curl -fsSL https://sluice.example/install.sh | sh
Start sluice serve --forward http://localhost:3000
Size of the binary

11 MB

One static binary, one SQLite file

Sluice is one static binary of about 11 MB, built for Linux, macOS and Windows on amd64 and arm64.

We keep every delivery in a single SQLite file, so there is no Redis, no Postgres and no queue to run.

Exponential backoff, schematic

Retries and replay

When a forward fails, we retry it with exponential backoff for up to 72 hours.

Any stored delivery can go to your service again with one command and its delivery ID.

Replay sluice replay <delivery-id>
Age limit

5 minutes

Signature checks and an age limit

We verify HMAC-SHA256 signatures on deliveries and reject any delivery that is older than 5 minutes.

The web UI and its search

Our web UI runs on port 8081, where you can search deliveries by path, header or body text.

We keep deliveries for 30 days by default, and you can set a different period with --retain.

Hosted service Account Telemetry

No hosted service, no account, no telemetry

Sluice runs only where you install it, because we offer no hosted service and ask for no account.

We collect no telemetry, and there is nothing to sign up for before you start the binary.

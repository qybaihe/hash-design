The inbox

A public URL. For your webhooks. We store every delivery. Then we forward it.

  • To your local service.
  • Or an internal one.

No hosted service. No account. No telemetry. You host it.

One binary

One static binary. About 11 MB. Written in Go.

Systemamd64arm64
Linuxyesyes
macOSyesyes
Windowsyesyes

Storage? One SQLite file.

  • No Redis.
  • No Postgres.
  • No queue to run.
1,800 Deliveries per second. On a 2-vCPU VM. Our own benchmark.

Two commands

Install first.

curl -fsSL https://sluice.example/install.sh | sh

Then start.

sluice serve --forward http://localhost:3000
The script install.sh

Retries and replay

A forward fails. We retry. Exponential backoff. Up to 72 hours.

Need it again? Replay it.

sluice replay <delivery-id>

Any stored delivery.

Signature checks

We verify signatures. HMAC-SHA256.

Older than 5 minutes? Rejected.

Web UI and retention

Port 8081. Search deliveries.

  • By path.
  • By header.
  • By body text.
Local web UI localhost:8081

We keep 30 days. That is the default. Change it: --retain.

Sluicea self-hosted inbox for webhooks

You get a public URL.

Sluice stores every delivery.

Then it forwards each one. Local or internal, your call.

No hosted service. No account. No telemetry.

install curl -fsSL https://sluice.example/install.sh | sh

The first run

One line starts it.

Point --forward at your app.

start sluice serve --forward http://localhost:3000
  1. A public URLYour webhooks land here.
  2. Every delivery, storedKept, so you can replay it.
  3. localhost:3000Or any internal service.
